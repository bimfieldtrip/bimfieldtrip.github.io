# ILLUSTRATION_NEEDED — AI 일러스트 제작 브리프 (Shanghai Guide v0.8)

라이선스가 확인된 실사를 구하지 못한 28곳입니다. 지금은 기존 SVG placeholder가 그대로 보이고, 아래 파일을 넣으면 교체됩니다.

## 공통 규격

- **비율 16:10 (권장 1600×1000px)**, 카드에서 `object-fit: cover`로 잘리므로 핵심 피사체는 가운데 70% 안에 두세요.
- 형식: **WebP** (품질 75~82, 파일당 250KB 이하 권장). 경로: `assets/guide/illustrations/<파일명>.webp`
- 스타일(통일감): 실사와 헷갈리지 않는 **완성된 풍경/건축/음식 일러스트**. 차분한 채색(수채·과슈 또는 세밀한 플랫 일러스트 중 하나로 **전체 통일**), 자연광, 사이트 팔레트(화이트·네이비·연한 블루)와 어울리는 톤. 이미지 안에 글자·간판 문구 넣지 않기.
- 카드 좌하단에 작은 `ILLUSTRATION` 표시가 자동으로 붙습니다(이미지에 직접 넣지 마세요).
- **금지:** 실제 브랜드 로고·워드마크, 라이선스 캐릭터(POP MART·MINISO·M&M'S 등), 실존 인물 얼굴, 실제 매장 사진을 베낀 구도.
- 아이콘 하나짜리 상징 그림은 안 됩니다 — "이 장소에 가면 어떤 풍경을 보게 되는가"가 한 장으로 보여야 합니다.

## 넣는 방법

1. 파일을 아래 경로에 저장
2. `js/data-guide.js` → `GUIDE_IMAGE_MANIFEST["<spot id>"]`의 `ready: false` 를 `ready: true` 로 변경
3. 파일이 없거나 로드에 실패하면 자동으로 기존 placeholder로 돌아갑니다.
